# 运行记录参考：`record.json`

每个运行目录都有自己的 `record.json`，用于回答“哪张图、哪个框、哪个模型、什么配置、用了多久、输出多大区域”。它不是人工审核报告，也不包含掩膜本身；实际分割像素保存在同目录的 `mask_*.png` 中。

## 输入与运行标识

| 字段 | 含义 |
|---|---|
| `purpose` | `dental_preexperiment` 为真实牙片预实验；`synthetic_environment_check` 为合成图环境检查 |
| `timestamp_local` | 写入记录时的本地时间，带时区偏移；不是程序开始时间 |
| `image_path` | 输入图像的绝对路径；合成检查为 `null`。分享记录时注意本机路径可能包含个人信息 |
| `image_sha256` | 图像解码并转为 RGB 后的像素字节 SHA256，**不是原始 PNG/JPG 文件的哈希** |
| `image_size_wh` | 原图尺寸 `[宽, 高]`，单位为像素；不是模型内部输入尺寸 |

## 模型与计算环境

| 字段 | 含义 |
|---|---|
| `model` | 模型名称，例如 `SAM2.1 Hiera Tiny` |
| `commit` | 官方 `sam2/` 仓库的 Git 提交号，不是本项目脚本的版本号 |
| `checkpoint_sha256` | 本地权重文件的 SHA256，用于追踪权重是否变化，不表示模型质量达标 |
| `python`、`torch` | 本次 Python 和 PyTorch 版本；不是完整依赖快照 |
| `device` | 推理设备，当前为 `cpu` |
| `threads` | PyTorch CPU 计算线程设置，默认 `4`，不是同时处理的图像数 |
| `precision` | 计算精度，当前为 `float32` |
| `cuda_postprocessing` | 是否启用可选 CUDA 后处理，当前为 `false` |
| `model_input_size` | 模型内部输入变换尺寸，当前为 `1024`；输出掩膜仍对应原图尺寸 |

## 耗时与逐牙结果

| 字段 | 含义 |
|---|---|
| `load_seconds` | 模型构建、权重加载及预测器初始化的阶段耗时，单位为秒 |
| `encode_seconds` | 整张图像的编码耗时，单位为秒；同图多个框复用这次编码 |
| `instances` | 逐实例结果数组，与输入 `boxes` 的顺序一致 |
| `instances[].instance` | 从 `1` 开始的实例编号；例如 `1` 对应 `mask_001.png`，不是临床牙位编号 |
| `instances[].box_xyxy` | 本次实际使用的 `[x1, y1, x2, y2]` 原图像素坐标；可包含小数 |
| `instances[].model_score_not_accuracy` | 模型内部质量估计，**不是准确率、Dice 或真实 IoU** |
| `instances[].mask_pixels` | 预测前景像素数量，不是正确像素数量，也不是平方毫米面积 |
| `instances[].decode_seconds` | 该框调用预测接口的耗时，单位为秒，不包含保存掩膜文件 |
| `ground_truth_available` | 当前脚本固定记录为 `false`，表示本流程未接入人工真值，并非自动判断数据集是否有标注 |
| `accuracy_metrics` | 当前为 `null`，表示没有计算精度指标，不代表精度为零 |

例如，新转换提示的 `outputs/DP100130-annotated-001/record.json`（路径相对于项目根目录） 中，关键结果为（以下仅摘录部分字段）：

```json
{
  "image_size_wh": [1722, 922],
  "load_seconds": 1.3836984999943525,
  "encode_seconds": 3.419418199977372,
  "instances": [
    {
      "instance": 1,
      "box_xyxy": [834.5449735449733, 566.2910052910049, 864.1746031746031, 657.2962962962961],
      "model_score_not_accuracy": 0.82798832654953,
      "mask_pixels": 1847,
      "decode_seconds": 0.23547039995901287
    }
  ],
  "ground_truth_available": false,
  "accuracy_metrics": null
}
```

这表示：模型根据一个框生成了 1847 个前景像素；内部得分约 0.828，**不能解释为准确率 82.8%**。三阶段耗时可按 `load_seconds + encode_seconds + 所有 decode_seconds 之和` 计算，此例约为 **5.04 秒**，但不包括程序启动、依赖导入、输入读取、文件保存和人工操作，不是端到端总耗时。

记录保存了实际框坐标，但不保存提示 JSON 的源路径、完整依赖、警告日志、内存峰值或人工审核结论。若后续修改 `inputs/` 中的提示，旧记录仍代表旧运行，应结合对应掩膜查看，不要把它当作当前输入的预测。
